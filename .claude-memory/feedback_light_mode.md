Не делать light mode для трейдинг/крипто сайтов.

**Why:** Потратили много времени на фикс контраста в light mode — мятный #00D4AA сливался с белым фоном, карточки не контрастировали, фоновые элементы (свечи, particles) были либо слишком яркими, либо невидимыми. В итоге решили убрать полностью.

**How to apply:** Для проектов типа TrendRider — только dark theme. Не предлагать light mode и не тратить время на его поддержку. Если пользователь просит — напомнить про этот опыт.
